# Healing Pocket - 治愈系AI小手机

这是一个完全基于单文件 HTML5 + PWA 标准打造的治愈系 AI 互动小手机应用。

## 🚀 GitHub Pages 一键部署指引

1. 在 GitHub 上新建一个公开仓库（例如 `healing-pocket`）。
2. 将本 ZIP 压缩包解压后的所有文件（`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` 等）上传到该仓库的根目录。
3. 点击仓库顶部的 **Settings** -> 找到左侧边栏的 **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 选择 `main`（或 `master`），路径保持 `/ (root)`，点击 **Save**。
5. 等待 1~2 分钟，GitHub Pages 将生成您的专属 HTTPS 链接（例如 `https://<username>.github.io/healing-pocket/`）。

## 📱 手机桌面安装 (PWA)

- **Android (Chrome / Edge / 夸克)**：
  使用手机浏览器打开您的 GitHub Pages 网站，点击右上角菜单，选择 **“添加到主屏幕”** 或 **“安装应用”**。
- **iOS (Safari)**：
  在 Safari 浏览器中打开该网站，点击底部的 **分享按钮 (带箭头的方框)**，向下滑动选择 **“添加到主屏幕”**。
- 安装后将以**原生全屏 App 独立窗口运行**，免去浏览器地址栏打扰，支持后台音乐常驻播放与离线秒开体验。
